# Erlebnis Egerland – GitHub-Pages-Website

Die Website besteht nur aus einfachen HTML-, CSS- und JavaScript-Dateien und kann kostenlos mit GitHub Pages veröffentlicht werden.

## Inhalte bearbeiten

- Texte stehen direkt in den jeweiligen Seiten (`index.html`, `ueber-uns.html` usw.). Platzhalter sind absichtlich als solche formuliert.
- Für eigene Bilder empfiehlt sich ein Ordner `bilder`. Ein Platzhalter kann dann zum Beispiel durch `<img src="bilder/mein-foto.jpg" alt="Beschreibung des Fotos">` ersetzt werden.
- Die Farben, Schriften und das Layout befinden sich zentral in `styles.css`.

## Kostenlos veröffentlichen

1. Bei [GitHub](https://github.com) anmelden und ein neues **öffentliches** Repository mit dem Namen `p-seminar-unterwegs-im-egerland` erstellen.
2. Alle Dateien dieses Ordners hochladen.
3. Im Repository **Settings → Pages** öffnen.
4. Bei „Build and deployment“ **Deploy from a branch**, Branch `main` und Ordner `/(root)` auswählen und speichern.
5. Nach kurzer Zeit ist die Seite unter `https://DEIN-GITHUB-NAME.github.io/p-seminar-unterwegs-im-egerland/` erreichbar.

Für die kürzere Adresse `https://DEIN-GITHUB-NAME.github.io/` muss das Repository genau `DEIN-GITHUB-NAME.github.io` heißen.
